MiniLM embeddings · ChromaDB · Ollama (local models)

Walk through the seven steps. The first row runs left to right, then step 4 hands the prompt down to step 5 and the second row runs right to left. The structured JSON decision is useful because it turns behavior into a few categorical features we can analyze: did it escalate, what kind of refusal, which team did it route to. Everything is logged as one JSONL row per call, together with the ids of the retrieved documents, so we can verify that the confidential canary was in the context under M1 and absent under M2. Models run locally through Ollama; no external API was used.
