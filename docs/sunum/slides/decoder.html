Features

Behavior: escalation, refusal type, routing team, length, time. Text: 22 style markers (pronouns, punctuation) + embeddings.

Fixed, simple model

L2 logistic regression, no tuning. A weak decoder that still succeeds proves the signal is real.

Leave-one-topic-out

Train on 19 topics, test on the 20th. The decoder cannot memorize topic words.

Randomized controls (mandatory): shuffle topic labels 500 times (p-value), shuffle rows, and run a placebo decoder on control rows. “Channel open” = p < 0.05 and AUC confidence interval above 0.5.

BLG558E · Security & Privacy · Final Project

The decoder plays the attacker. Its job is a binary guess per topic. We keep it deliberately simple and fixed so that a positive result means the signal exists in the data, not that we found a clever model. Leave-one-topic-out evaluation prevents the classic mistake of memorizing topic keywords. Randomized controls estimate how high the score can get by chance with the same procedure, which gives us p-values and a noise floor.
