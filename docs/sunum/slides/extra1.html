This is an extension of the main work, not part of the original experiment. The question: user A shares private data with the bot; does it leak to user B, who only asks legitimate questions? We built three memory modes. X1 searches the shared memory of all users. X3 keeps one running summary of all users' notes in every context. X2 isolates memory: the search is filtered by the entry owner before similarity ranking, so A's note is not even a candidate for B. Because B's own messages are never written to memory, B's context under X2 equals having no memory at all, which makes X2 our negative control.
