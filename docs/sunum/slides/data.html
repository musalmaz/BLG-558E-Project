Why canaries? We write them ourselves, so we know exactly which topics are confidential (ground truth) and which secret details (markers such as “24th”) to look for in replies.

Real Enron emails give realistic background noise. The 30 canary emails are fabricated but realistic and contain secret details on purpose: dates, numbers, budgets. We call these markers; if a marker appears in a reply, that is direct leakage. Ten topics have three confidential canaries each (positive class), ten topics have none (negative class). The decoder later has to tell these two classes apart from behavior alone.
