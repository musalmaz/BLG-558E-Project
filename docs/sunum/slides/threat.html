Threat model: an ordinary customer

Attacker

Sends only natural, legitimate messages. No prompt injection: no “ignore your instructions” attacks.

What it observes

Reply text, decision fields (escalated, refusal type, routing team) and response time. It never sees the documents.

Ethics

Own replica environment. Data: public Enron emails and fabricated canary documents. No real product or personal data.

Why legitimate messages only? It shows leakage that needs no attack at all: ordinary use is enough.

Task for the attacker: for a given topic, decide “does the company hold a confidential document about it?”

BLG558E · Security & Privacy · Final Project

Limiting the attacker to legitimate messages is a deliberately weak adversary. If leakage exists even there, it exists for every customer, not only for malicious ones. We reduce everything to one binary question per topic because we plant the canary documents ourselves and therefore know the ground truth.
