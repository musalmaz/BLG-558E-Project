Limitations: what we cannot claim

Scale

10+10 topics, 5 variants, one repetition in most analyses. Small effects cannot be excluded.

Models

Two small local open-weight models. No commercial model (no API key).

Authorship

Canaries, messages and secret definitions were written by one author. “What is secret” is a policy choice.

We do not claim “no behavioral channel”. The agent almost never escalates and rarely refuses, so there is little behavior to measure. “Not found” is not the same as “not there”.

No multiple-testing correction: single-cell p ≈ 0.03 results are hints, not proof. Latency is unreliable on shared hardware. Utility is measured with a simple marker-recall proxy, not answer correctness.

BLG558E · Security & Privacy · Final Project

We want the audience to leave with an accurate picture. The positive findings are solid within this setup: weak ACL leaks, strong ACL closes the text channel, shared memory leaks across users. The negative finding about behavioral fields is the one that must not be over-read.
