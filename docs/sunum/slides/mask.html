Content leakage closed, utility kept; the topic’s existence still leaks. A masked document still says that the topic exists. “Approved line” = the agent says the officially approved sentence, e.g. “we do not comment on rumours”.

oracle = hand-listed secret spans (upper bound) · rule = frozen regex rules

Masking is applied only to confidential chunks, just before they enter the prompt. Oracle masks a hand-written list of secret spans; rule uses generic regex rules frozen before the run. Direct leakage drops to zero for both models, and answer quality stays near the undefended agent, unlike M2 and scoped context. But the text-style channel stays open: gemma3 AUC is 0.84 with oracle masking and 0.69 with rule masking, against 0.45 for M2. A masked document still tells the model that a confidential topic exists, and the model reflects that in its style; replies also sometimes copy the placeholder, which is a hint by itself.
