ACL: who may read which document?

An Access Control List labels every document. The agent serves an external customer, so only some labels should ever reach the language model.

public

Anyone may see it.

Example: press release, FAQ

internal

Employees; useful for answers.

Example: billing procedure, vacation policy

confidential

Only a few people.

Example: “Project Falcon merger, board votes on the 24th”

M1 · weak ACL

Search returns all labels. The prompt only says “do not reveal confidential content”. The model still reads the secret.

M2 · strong ACL

Confidential documents are filtered at search time. The model never sees the secret, so it cannot write it.

Direct questions (20): M1 leaked in 16/20 (gemma3) and 13/20 (qwen2.5); M2 leaked in 0/20.

BLG558E · Security & Privacy · Final Project

M1 is a realistic, common setup: confidential documents live in the same index and the only protection is an instruction in the prompt. M2 enforces the ACL where it should be enforced, before the model. The direct-question check confirms the ACL assumption: under M2 no secret reaches the answer, so any remaining leakage must be a side channel.
