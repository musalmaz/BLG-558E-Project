Confidential documents the agent can read (merger plans, layoffs, legal settlements)

↑ read by the agent

Direct leakage

The reply contains the secret: “The board votes on the 24th.”

Side-channel leakage

The reply never states the secret, but its tone, refusals, routing or timing reveal that a confidential document exists.

Research question: From legitimate messages only, can an observer tell whether the agent holds confidential documents on a topic?

BLG558E · Security & Privacy · Final Project

Modern service agents use retrieval-augmented generation (RAG): the message is matched against company documents, the best matches are given to a language model as context, and the model writes the reply. Some of those documents are confidential. The usual defense is a prompt rule: do not reveal confidential content. We ask a harder question: even if the agent never writes a secret, can its behavior (tone, refusals, routing, response time) reveal that confidential material exists? A bank-teller analogy helps: the teller never tells you what is in the vault, but if they suddenly turn formal and send you to the manager whenever you ask about one topic, you learn that something is there.
